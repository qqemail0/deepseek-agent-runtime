# 路线图和待优化项

## P0：正确性和安全

- 强化 Windows、macOS、Linux 的 shell 风险识别。
- 增加权限弹窗、拒绝工具路径、full access 策略测试。
- 增加文件工具和 desktop open 的路径穿越测试。
- 增加桌面 UI 截图回归测试。
- 在 CI 中加入依赖漏洞扫描。

## P1：Token 和缓存优化

- 增加显式 prefix warmup 模式，但必须由用户确认额外首轮成本。
- 增加按模型记录的本地前缀历史，区分本地已见前缀和远端真实缓存状态。
- 实现 Agent Loop 内渐进式工具 schema 加载。
- 增加 AST/import graph 上下文选择。
- 增加 BM25 + 可选 embedding 混合检索。
- 改进对话摘要，把稳定事实和未完成的波动任务分开保存。

## P2：桌面端 Agent 能力

- 增加打开 URL、文件、应用之外的电脑控制工具。
- 增加安全动作规划器，意图不明确时先确认目标。
- 增加完成文件预览和 diff viewer。
- 增加任务目标跟踪器，用证据判断 done、partial、failed。
- 增加工作区 profile 和每个对话独立运行时设置。

## P3：扩展能力

- 实现真实 MCP server 注册、schema 加载和沙箱策略。
- 增加子智能体，支持隔离上下文预算和压缩结果交接。
- 增加 hooks：工具前校验、工具后格式化、测试、安全检查。
- 增加 OpenAI、Anthropic、Gemini、本地模型 provider 插件。

## P4：发布和分发

- 打包签名安装器。
- 增加自动更新。
- 增加崩溃报告，并自动脱敏密钥和私有路径。
- 发布示例工作流和架构图。

## 当前最值得优先改的点

- 首次请求命中率显示需要更明确地区分“真实远端命中”和“本地可复用前缀预测”。
- 工具调用 schema 还不是完全渐进式加载。
- MCP 还是占位实现。
- 子智能体尚未实现。
- 桌面端还缺少可视化 diff、文件预览和截图回归测试。
